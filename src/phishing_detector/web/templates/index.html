{{ t("Frequently asked questions", "常见问题") }}

{{ t("What is a phishing site?", "什么是钓鱼网站？") }}
{% if zh %}

钓鱼网站是对真实网站（你的银行、邮箱、快递公司）的仿冒，目的是骗你在上面输入密码或银行卡号。这类网站通常只建立了几天，而且往往看起来很逼真。

本工具会像调查人员一样审视它：谁注册了这个地址、它建立了多久、页面要你提供什么，以及它是否盗用了其他公司的图片。然后把发现的情况解释给你听。

{% else %}

A fake copy of a real site (your bank, your email, a delivery company) built to make you type a password or card number into it. They are usually days old and usually look convincing.

This tool looks at one the way an investigator would: who registered the address, how old it is, what the page asks for, and whether it borrows another company's images. Then it explains what it found.

{% endif %}
{{ t("How do I read an address myself?", "我自己该怎么看懂一个网址？") }}
{% if zh %}

在网址中找到注册域名。域名的结尾可能由好几段组成，例如 co.uk 或 com.cn，所以只数最后两段并不总是对的。放在注册域名前面的熟悉公司名称，并不能证明网站归这家公司所有。在 secure.paypal.com.account-verify.co 中，真正的网站是 account-verify.co，它前面那些让人放心的字眼，都是设置这个地址的人自己写上去的。

本页顶部的输入框会为你粘贴的任何网址标出这一部分，让你在做决定之前先看清它落在哪里。

{% else %}

Look for the registered domain in the address. Its ending may have several parts, such as co.uk, so counting the last two words does not always work. A familiar company name placed before the registered domain does not prove ownership. In secure.paypal.com.account-verify.co the site is account-verify.co, and every reassuring word in front of it was typed by whoever set the address up.

The box at the top of this page marks that part for any address you paste, so you can see where it falls before you decide anything.

{% endif %}
{{ t("Is it safe to paste a suspicious link here?", "把可疑链接粘贴到这里安全吗？") }}
{% if zh %}

检查工具在受限的环境中获取页面，跟随跳转，并检查返回的内容。它不会填写表单或输入账号密码，下载也会被拦截。在开启相关功能时，它可以运行页面脚本，以检查需要脚本才能显示的内容。可疑页面不会在你的浏览器中打开。

{% else %}

The checker fetches the page in a restricted environment, follows redirects, and inspects the returned content. It does not fill in forms or enter credentials, and downloads are blocked. When enabled, it can run page scripts to inspect content that needs them. The suspicious page is not opened in your browser.

{% endif %}
{{ t("What happens when the rules and the model disagree?", "规则和模型的判断不一致时会怎样？") }}
{% if zh %}

从外部看，正规的登录页面和窃取账号密码的钓鱼页面几乎可以一模一样，所以固定规则和评分模型有时会得出相反的结论。一条有把握的规则，无论指向哪个方向，都会胜出：一个已知可信的域名不会因为一个紧张的分数而被改判。而当各项检查看过证据仍无法决定时，页面会如实这样说，而不是让分数替它选一个词。所以“无法确定”的意思是各项检查本身拿不准，而不是分数刚好接近判定线。

{% else %}

Legitimate sign-in pages and credential phishing can look almost identical from the outside, so a fixed rule and the scoring model sometimes land on different sides of a case. A confident rule, in either direction, still wins - a known-good domain is not recoloured by a nervous score. And when the checks look at the evidence and cannot decide, the page says exactly that rather than letting the score pick a word for it - so "not sure" means the checks were unsure, not that the number was close.

{% endif %}

{{ t("What happens to the links I check?", "我检查的链接会被怎样处理？") }}
{% if zh %}

地址会发送到本网站的服务器，由服务器自己去访问那个页面，而不是通过你的浏览器，也不会带上你的 Cookie 或登录状态，所以被检查的网站看到的是检查工具的访问，而不是你的访问。为了检查域名，服务器还会向外部服务查询它的信息：域名注册局、公开的证书日志、DNS、网络归属查询，如果本网站配置了的话，还有 Google 安全浏览（Safe Browsing）。

{% if feedback_enabled %}

这个检查工具会把收集到的证据保存在服务器上，以便日后报告和复查某个结果。如果判断或证据有误，请在结果页使用“报告问题”。

{% else %}

结果显示给你之后，或者两分钟后结果仍未显示，服务器上就不会保留任何关于这次检查的信息。和所有网站一样，托管服务商的请求日志会在一段有限的时间内记录被请求的地址，其中包括你检查的链接。

{% endif %}

你的检查结果只保存在这个浏览器里，在页面顶部的“历史记录”中，每一条都可以重命名或删除。删除一条会把它和它保存的结果一起从这个浏览器中删除。

{% else %}

The address goes to this site's server, which visits the page itself, not through your browser and without your cookies or logins, so the site you are checking sees a visit from the checker, not from you. To check the domain, the server also asks outside services about it: domain registries, public certificate logs, DNS and a network-ownership lookup, and Google Safe Browsing if this site has it set up.

{% if feedback_enabled %}

This copy of the checker keeps the evidence it collects on its server, so a result can be reported and reviewed later. Use Report a problem on a result to flag a wrong verdict or incorrect evidence.

{% else %}

Nothing about your check is kept on the server after your result has been shown, or after two minutes if it never is. Like any website, the hosting provider's request logs record the addresses requested, which include the link you checked, for a limited time.

{% endif %}

Your results are kept only in this browser, under History in the header, where any of them can be renamed or removed. Removing one deletes it and its saved result from this browser.

{% endif %}
